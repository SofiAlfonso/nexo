# Documentación de experimentos de fallos

**Responsabilidad**: documentar el diseño, alcance, hipótesis y criterios
de éxito/rollback de los experimentos de fallos controlados (chaos
engineering) de NEXO.

**Qué no debe implementarse aquí**: scripts ni configuración ejecutable de
los experimentos (ver [chaos/](../../chaos/README.md)). Solo documentación.

**Componente relacionado**: C2 (coordinador local), D1 (persistencia
transaccional local) y la conexión C2–C4, según el experimento.

**Decisiones pendientes**: plantilla de documentación por experimento y
criterios formales de aceptación de cada prueba (RED-01, SER-06, BD-01,
REC-01).
