# Decisiones de arquitectura (ADRs)

**Responsabilidad**: registrar las decisiones de arquitectura relevantes de
NEXO (contexto, opciones consideradas, decisión y consecuencias).

**Qué no debe implementarse aquí**: código, configuración ni resultados de
pruebas. Solo el registro de decisiones y su justificación.

**Componente relacionado**: transversal a toda la arquitectura del
proyecto.

**Decisiones pendientes**: plantilla concreta de ADR a utilizar y
numeración/convención de nombres de archivo.
