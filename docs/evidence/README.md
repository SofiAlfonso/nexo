# Evidencia de pruebas

**Responsabilidad**: alojar evidencia curada de pruebas y experimentos
(capturas, resúmenes, reportes) relevante para revisión y auditoría.

**Qué no debe implementarse aquí**: datos personales, secretos, dumps de
producción ni identificadores de boleto/QR completos. Solo evidencia
anonimizada y resumida.

**Componente relacionado**: transversal — cubre evidencia de todos los
componentes (C1–C5, D1–D2) y de los experimentos de fallos.

**Decisiones pendientes**: formato y retención de la evidencia, y proceso
de anonimización antes de subir cualquier archivo.
